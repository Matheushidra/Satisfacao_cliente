## 📝 Sobre o Projeto
Este projeto é uma atividade acadêmica que consiste no desenvolvimento de um sistema simples em Python para a agência de marketing **TudoWeb**. O objetivo do programa é coletar e contabilizar as opiniões dos clientes sobre o atendimento prestado, gerando um relatório final de satisfação.

## 🎯 Objetivos do Exercício
Desenvolver um programa que:
- Solicite nome, idade e opinião do usuário (1: EXCELENTE, 2: BOM, 3: RUIM).
- Utilize **estruturas de repetição** para entrevistar um grupo de pessoas (configurado para 10 testes, com meta final de 50).
- Utilize **estruturas de decisão** para categorizar e contabilizar os votos.
- Exiba ao final a quantidade exata de respostas "EXCELENTE" e "RUIM".

## 🧠 Competências e Habilidades Desenvolvidas
- Implementação de algoritmos de programação.
- Codificação utilizando técnicas de programação estruturada.
- Desenvolvimento de raciocínio lógico.
- Uso prático da estrutura de repetição `for`.
- Uso prático de estruturas condicionais `if`, `elif` e `else`.
